## Overall shape

The existing scripts (`alien_generator`, `image_painter`, the JSON↔Text translators) become the **engine**; the GUI is a thin layer on top that never duplicates that logic. I'd add a new dependency (PySide6 isn't in `pyproject.toml` yet — only Pillow is) via `uv add pyside6`, plus `pytest-qt` as a dev dependency for GUI smoke tests.

New layout under `src/gui/`:

```
src/gui/
  app.py              # entry point: QApplication + MainWindow
  main_window.py      # MainWindow: File > New / Open / Exit
  alien_window.py      # AlienWindow: File > Save / Save As / Close
  pixel_grid.py         # PixelGridWidget — the clickable canvas

  new_alien_dialog.py   # width/height/palette form
  alien_io.py            # Qt-free load/save/new_grid helpers
```

`alien_io.py` is the key seam: it wraps `json.load`/`json.dump` and the existing `alien_json_to_text`/`alien_text_to_json` translators behind `load_alien(path)` / `save_alien(path, grid)`, dispatching on file extension. Keeping it Qt-free means it's testable with plain `pytest`, same as the current `tests/` — the GUI tests (via `pytest-qt`) only need to cover a handful of interaction smoke tests, not the format logic.

## MainWindow

- **New** → `NewAlienDialog` (width/height spin boxes, palette combo populated from `alien_generator`'s known palette names) → builds a blank grid + palette → opens an `AlienWindow`.
- **Open** → `QFileDialog` filtered to `*.json *.txt` → `alien_io.load_alien(path)` → opens an `AlienWindow` populated from the file.
- **Exit** → confirm, then close every open `AlienWindow` (each still runs its own unsaved-changes check and can cancel the whole exit), then `QApplication.quit()`.
- MainWindow holds a list of live `AlienWindow` references — otherwise Qt garbage-collects windows with no Python reference holding them.

## AlienWindow

Its own `QMainWindow` with its own menu bar (Qt supports this per-window). Central widget: `PixelGridWidget` + `PaletteWidget` side by side. It tracks `grid`, `palette`, `path` (`None` until first save), and a `dirty` flag; window title shows filename + a `*` when dirty.

- **Save**: if `path` is set, `alien_io.save_alien(path, grid)`; otherwise behaves like Save As.
- **Save As**: `QFileDialog.getSaveFileName`, pre-filled with the current path if any; format chosen by the extension picked.
- **Close**: standard Save/Discard/Cancel prompt if dirty.

## PixelGridWidget

A single custom `QWidget` that paints all cells itself (`paintEvent` + `fillRect` per cell, same mental model as `image_painter`'s scale-block rendering) rather than one `QPushButton` per pixel — much cheaper and scales fine up to the 32×32-ish grids this app already generates. `mousePressEvent` maps click coordinates to `(row, col)`, paints the currently-selected color into the grid, and emits a signal the window uses to mark itself dirty.

## PaletteWidget

A strip of fixed-size swatches, one per palette color. Single click selects (highlighted border, emits the active paint color). Double click opens `QColorDialog` to redefine that swatch — matches "standard interface" in the prompt well, since that's exactly how most simple paint tools do palettes.
