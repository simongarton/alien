     Context

     prompts/prompt1.md asks to "set up the main functionality" by creating the
     two
     scripts described in readme.md: a generator that turns alien DNA into a

     This is the reusable core that later prompts will drive from a website, an
     API, or

     produces

     alien_generator.py

     Signature (type-hinted per conventions):
     def generate_alien(
         width: int = 16,
         height: int = 16,
         background: str = "#ffffff",
         palette: str = "cga",
         eyes: int = 2,
         bigeyes: bool = False,
         legs: int | None = None,      # None -> random 2..5
         arms: int = 0,
         shape: str | None = None,     # None -> random choice
     ) -> list[list[str]]:
     Returns a list of height rows, each a list of width hex-colour strings.
     Background cells hold the background hex; body/features hold palette or
     feature
     colours.

     Palettes (helper build_palette(name, background) -> list[str]):
     - cga — the fixed 16-colour CGA hex list.
     - green/red/blue — shades interpolated between the two endpoints in the
     README (#006400→#00FF00, etc.), a fixed number of steps.
     - full — sampled RGB colours.
     - Bug trap from README: filter the chosen background out of the palette so
     a
     body pixel can never equal the background (applies to all palettes; matters
     most
     for cga/full).

     Symmetry + shape (helper body_mask(width, height, shape) -> set[(r,c)]):
     - Build a boolean/coordinate mask for the requested shape (circle, oval,
     square,
     triangle, triangle-inverted), leaving a bottom margin so legs can hang
     below.
     - Generate the left half only (including the centre column when width is
     odd),
     randomly dropping some in-mask cells for the "irregular" look, then mirror
     left→right. This guarantees left-right symmetry.
     - Fill masked body cells with palette colour(s).

     Eyes (place_eyes): placed symmetrically in the upper body.
     - 2 eyes: mirrored left/right pair. 3 eyes: a centre eye on the axis + a
     mirrored
     pair.
     - bigeyes=False: single white pixel each. bigeyes=True: 2×2 white block
     with one
     black pixel in the bottom-left or bottom-right (mirrored so the pair looks
     outward-facing).
     - Fit guard: if the grid is too small for the requested eyes/bigeyes,
     degrade
     gracefully (fall back to single-pixel eyes / fewer eyes) rather than crash
     — the
     README explicitly flags this risk.

     Legs (add_legs): legs vertical 1-px columns hanging from the body bottom,
     distributed symmetrically. Arms (add_arms): arms vertical columns sticking
     up or out to the sides, symmetric; default 0 means none.

     image_painter.py

     def paint_image(alien: list[list[str]], filename: str = "alien.png",
                     scale: int = 20) -> str:
     - Create Image.new("RGB", (width*scale, height*scale)), fill each cell
     block with
     its hex colour (converted via ImageColor.getrgb), save PNG, return the
     path.
     - scale is an added param (README doesn't mention it) so a 16×16 alien
     renders as
     a viewable image instead of a 16-px speck; defaults keep the call one-arg
     simple.
     Flagging this as my addition — say the word if you'd rather it paint
     1px:1cell.

     main.py demo

     Replace the stub: call generate_alien() with defaults, pass the grid to
     paint_image(), print the output path. Runnable via uv run python 
     src/main.py.

     Tests

     hex string;
     no body pixel equals the background; left-right symmetry holds; eye count
     matches;
     legs=None yields 2..5; small-grid eye fit guard doesn't crash.
     - Painter: writes a file at the given path with pixel size width*scale × 
     height*scale; custom filename respected.
